# Demo script

A short narrative for a live or recorded demo. Replace bracketed items with real
values once the features exist.

1. **Problem (30s).** Testimony and civic incident reports are hard to organize
   and easy to misstate. N-ATLAS Civic Evidence documents them without deciding
   what is true.
2. **Case setup (1m).** Create a case and record consent. Show that permissions
   are enforced by the backend.
3. **Evidence (2m).** Add audio, show the transcript, and run claim extraction.
   Point out that every claim starts `unverified` and links to a segment.
4. **Review (2m).** Accept one claim, edit another, reject a third, and add notes.
5. **Civic guidance (1m).** Look up an official procedural source and show that it
   is displayed separately from testimony.
6. **Report (1m).** Generate a report, show review status and citations, and
   export it.
7. **Close (30s).** State measured results only; keep targets labeled as targets.

Keep a backup recording. Do not present planned behavior as implemented.
