# Challenge submission materials

This directory collects materials needed to present and verify the project for the National AI Innovation Challenge.

## Expected materials

- `demo_script.md` — a timed 3–5 minute walkthrough of the implemented system.
- `team_profile.md` — team roles and eligibility/endorsement details appropriate for submission.
- `requirements_checklist.md` — challenge requirements mapped to implementation evidence.
- `evidence_index.md` — paths to integration proof, benchmark results, deployment checks, and real-world validation.

## Submission discipline

- Use only claims supported by the running artifact, source code, test outputs, or independently reviewable records.
- Clearly identify limitations, unavailable model capabilities, and incomplete work.
- Include proof of actual N-ATLAS integration and base-versus-fine-tuned evaluation where required.
- Use synthetic or consented demo material; do not expose private testimony or personal information.
- Verify the deadline, eligibility, endorsement, registration, and submission format against the current official challenge instructions.

This directory organizes evidence; it is not proof that requirements have already been met.
